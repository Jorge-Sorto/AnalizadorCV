# Seguridad

- No almacenar CV reales; anonimizar cualquier caso utilizado.
- Mantener claves exclusivamente en `.env` local, secretos de GitHub o servidor.
- No registrar textos completos, tokens ni prompts con información personal.
- Limitar CORS a los orígenes utilizados en producción.
- Reportar vulnerabilidades de forma privada al responsable del repositorio.
